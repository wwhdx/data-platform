**调度注意**：仅 `registerConnector` 不会 cron 采集；`scheduler.schedule()` 且不看 YAML `enabled` 会导致「配置关闭仍定时跑」。B13 目标：`enabled: true` + 有 Connector + 合法 `schedule` 才注册 cron。

### 4.2 四轨并行

```
轨 1 平台价值（父仓）          轨 2 数据面（本子包）        轨 3 质量/运维        轨 4 子包闭环（I 轨）
──────────────────────   ─────────────────────────   ────────────────   ──────────────────────────
C2 DataPlatformClient    A4 Semantic Scholar         B8 API 探活      I1 mock embed
       │                 A7 arXiv OAI（P2）          A8 段落分块      I2 FixtureConnector
       ▼                 A12 re-embed（可选）        C4 admin 页      I3–I4 pipeline 集成测
C3 searchProvider 注入                                                         │
       ↑ 接 C2/C3 前可先跑 I 轨 ─────────────────────────────────────────────────┘
```

轨 1 与轨 2、轨 4 **可并行**（不同目录/无父仓依赖）；轨 3 建议在有一定入库量后做 A8。
