- `schedule` 字段来自展开后配置或 `collection_schedules` 表，与 [外部数据源配置热更新方案](./外部数据源配置热更新方案.md) 一致。

## 5. 不做的事（明确排除）

| 排除项 | 理由 |
|--------|------|
| Embedding 队列化 | 日均采集量 < 1000 条时不需要，当前 fire-and-forget + 日志够用 |
| Stage 3 段落级分块 | 需要先有长文本数据（当前仅 title+abstract），分块策略收益有限 |
| Stage 2 LLM 富化 | 属于 engine-core 侧能力，data-platform 只做规则/NER 轻量抽取 |
| `/api/context` 端点 | 已明确移除，由 engine-core summarizeContext 替代 |
| 知识图谱 (Neo4j) | Phase 3，需要 Connector 覆盖先到位 |

## 6. 风险与缓解

| 风险 | 缓解 |
|------|------|
| World Bank API 无限制 → 可能被限流 | `paginateOffset` 中每页之间加 `sleepMinInterval` |
| Semantic Scholar 商业授权未完成 | 默认 `enabled: false`，仅开放给非商业使用 |
| YAML 解析库新增外部依赖 | `js-yaml` 是 Node.js 生态事实标准，零原生依赖 |
| 配置文件与数据库不同步 | `config diff` 命令 + 启动时 `config validate` 检查 |
