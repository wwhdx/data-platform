## 1. 目标与范围

### 1.1 目标

在 [波次 0–4](./剩余数据源接入实施方案.md#13-波次总览)（17 个 Connector 已全部落地）基础上，对照 [真实行业获取指南](../knowledge/真实行业获取指南.md) 梳理**下一批可合法接入**的外部数据源，给出优先级、协议映射与实施波次，供排期与 YAML/`interface_profiles` 规划使用。

### 1.2 非目标

- 不重复维护已实现 Connector 的端点/字段（见 [data-sources.md](../data-sources.md)）
- 不含商业订阅源（Scopus、Crunchbase、Bloomberg 等）的采购谈判
- 不含无官方 API、需爬虫的中国本土源（CNIPA、巨潮、百度指数等）的实施方案——仅登记为「暂缓」

### 1.3 已实现基线（2026-05-20）

| 维度 | 数量 | 真源 |
|------|------|------|
| YAML `sources[]` | 18（含 Legacy `arxiv`） | `config/sources.yml` |
| 运行时 Connector | 17 | `src/connectors/bootstrap.ts` `REGISTERED_CONNECTOR_IDS` |
| 指南 MVP 四件套 | ✅ | OpenAlex + S2 + arXiv + 政府/SEC/专利 |

指南 [§六 启动期路线](../knowledge/真实行业获取指南.md#六给启动期团队的实战路线) 第 2–3 周「免费源」已基本覆盖；本文档聚焦**垂直补洞**与**已有源加深**。

## 4. 实施波次（5–8）

```
波次 5（学术加深）     bioRxiv + medRxiv → CORE → OpenCitations
波次 6（医药垂直）     ChEMBL → PubChem →（可选 UniProt via NCBI db 扩展）
波次 7（行业扩展）     Materials Project → EIA → Eurostat / OECD
波次 8（舆情补全）     Stack Overflow → Reddit 启用 → GDELT
```

| 波次 | 源 | 预估 | 依赖 | RAG 主路径 |
|------|-----|------|------|-----------|
| 5 | `biorxiv_oai`、`medrxiv_oai`、`core` | 3–4d | `arxiv_oai` 模板 | 是 |
| 5+ | `opencitations` | 1–2d | — | 图谱为主 |
| 6 | `chembl`、`pubchem` | 3–4d | — | 是（医药） |
| 7 | `materials_project`、`eia` | 2–3d | — | 部分 |
| 7+ | `eurostat`、`oecd` | 2–3d | 指标类，同 `worldbank`/`fred` | 低 |
| 8 | `stackoverflow`、Reddit 启用 | 2d | `reddit` 已有 | 中 |
| 8+ | `gdelt` | 3–5d | GCP / BigQuery | 中 |

**与已有源加深并行**：SEC-B、D5 续、YT-B 可与波次 5 同 sprint。

### 4.1 每源接入铁律

与 [剩余数据源接入实施方案 §1.2](./剩余数据源接入实施方案.md#12-实施铁律接入点) 相同：`connectors/<id>.ts` → `index.ts` → `bootstrap.ts` → `sources.yml` → 单测 → `data-sources.md` → ENV。
