## 1. 目标与范围

### 1.1 目标

在 [波次 0–4](./剩余数据源接入实施方案.md#13-波次-04-完成与后续)（17 个 Connector 已全部落地）基础上，对照 [真实行业获取指南](../knowledge/真实行业获取指南.md) 梳理**下一批可合法接入**的外部数据源，给出优先级、协议映射、**数据形态**、实施波次与 profile/ENV 规划，供排期与 YAML/`interface_profiles` 使用。

**编排原则（v1.8 · 真源优先）**：

1. **先加深已有 `primary` / `registry` Connector**（PMC-A、SEC-B），再接入新的真源垂直库（ChEMBL、PubChem、EIA…）。
2. **聚合商（`aggregator`）与镜像（`mirror`）不单独占主波次**；`core` 保持 fallback；`google_patents` 日常 RAG 不依赖。
3. **图谱/富化（`graph` / `enrich_metadata`）** 与正文采集解耦（波次 5b 已完成）；不再前置到正文波次之前。
4. 新 Connector 立项须标注 **§7 角色**；与同簇 `main` 源重复者降级或合并为 processor。

### 1.2 非目标

- 不重复维护已实现 Connector 的端点/字段（见 [data-sources.md](../data-sources.md)）
- 不含商业订阅源（Scopus、Crunchbase、Bloomberg 等）的采购谈判
- 不含无官方 API、需爬虫的中国本土源（CNIPA、巨潮、百度指数等）的实施方案——仅登记为「暂缓」
- **per-source 端点与字段真源**：落地时在 `data-sources.md` 开节；本文只写规划级决策

## 7. 数据源角色、重叠簇与采集策略

> **YAML 注释真源**：`config/sources.yml` 各 `sources[]` 条目上方 `# role:` / `# collect:` / `# cluster:` 与本节一致。  
> **背景**：[真实行业获取指南](../knowledge/真实行业获取指南.md) 列出的源并非全是「独家内容真源」；并行接入多个聚合商会导致同一 DOI/专利号多次入库。

### 7.1 角色定义

| 角色 | 含义 | 是否独家正文 | 典型源 |
|------|------|-------------|--------|
| `primary` | 内容在此平台**首次发布** | ✅ | arXiv、bioRxiv、SEC、GitHub |
| `registry` | **标识符/元数据**登记权威，正文在出版商 | ⚠️ 元数据权威 | CrossRef（DOI）、ClinicalTrials（NCT） |
| `aggregator` | 从多源合并论文/专利元数据或全文索引 | ❌ 高重复 | OpenAlex、Semantic Scholar、CORE |
| `graph` | 引文**边**或关系数据，非论文正文 | 边独家 | OpenCitations（COCI） |
| `mirror` | 官方数据的再打包/全球合并 | ❌ 与真源重叠 | Google Patents BigQuery |
| `secondary` | 非官方或二手封装 | ❌ | Yahoo Finance |

**富化层（非 Connector）**：`unpaywallEnrich` — DOI→OA URL，不产新文档，设计正确。

### 7.3 重叠簇与互斥规则

```
学术 metadata 簇：openalex ↔ semanticscholar ↔ crossref ↔ pubmed（同 DOI/PMID）
  → 规则：图谱源 openalex XOR semanticscholar；pubmed 主采生物医学；crossref 补 DOI

学术 preprint 簇：arxiv_oai · biorxiv_oai · medrxiv_oai（发表后进 pubmed，DOI 可跨源）
  → 规则：三源均可 main；远期按 DOI 跨源合并（代码未实现）

学术 fulltext 簇：core 索引 arXiv/PMC/仓储 OA → 与 preprint/pubmed 重叠
  → 规则：core 仅 fallback；优先 PMC-A（pubmed 扩展）

引文 graph 簇：opencitations vs OpenAlex/S2 引文 API
  → 规则：opencitations 采边；不对同一 DOI 集再拉 S2 citations

专利簇：patentsview (US) + epo_ops (EP) + google_patents (全球镜像)
  → 规则：日常 RAG：US→patentsview、EP→epo_ops；google_patents 仅 BigQuery 分析

宏观簇：fred ↔ worldbank（部分 GDP/通胀序列概念重叠）
  → 规则：按 series id 选型，勿按标题重复采

金融簇：sec_edgar（真源） vs yahoo_finance（二手行情）
  → 规则：基本面只信 SEC；Yahoo 仅行情
```
