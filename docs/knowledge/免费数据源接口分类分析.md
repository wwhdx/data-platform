## REST API — Query Param Key 认证

认证方式：API Key 通过 URL Query Parameter 传递（`?api_key=xxx`）。实现最简单，直接在 URL 拼接即可。

### OpenAlex

| 属性 | 值 |
|------|-----|
| Base URL | `https://api.openalex.org` |
| 认证 | `?api_key=YOUR_KEY`（可选，无 Key 也可访问） |
| 速率限制 | 100,000 次/天 |
| 响应格式 | JSON |
| 许可 | CC0（完全开放，可商用） |
| 数据规模 | 2.4 亿+ 学术作品 |
| 核心端点 | `/works`, `/authors`, `/institutions`, `/sources`, `/funders`, `/topics`, `/text` |
| 分页方式 | Offset（`page`/`per_page`）+ Cursor（大数据集 `cursor`） |
| Connector 状态 | **✅ 已实现** `src/connectors/openalex.ts` |

### PubMed / NCBI E-utilities

| 属性 | 值 |
|------|-----|
| Base URL | `https://eutils.ncbi.nlm.nih.gov/entrez/eutils/` |
| 认证 | `?api_key=YOUR_KEY`（免费申请） |
| 速率限制 | 无 Key: 3次/秒；有 Key: 10次/秒 |
| 响应格式 | XML（默认）/ JSON（`retmode=json`） |
| 许可 | 免费，可商用 |
| 数据库覆盖 | PubMed、PMC、Gene、Nuccore、Protein 等 38 个 |
| 核心工具 | `esearch`, `efetch`, `esummary`, `einfo`, `elink`, `epost`, `egquery`, `espell`, `ecitmatch` |
| 分页方式 | WebEnv + query_key（服务端 History 机制） |
| Connector 状态 | **❌ 未实现** |

## OAI-PMH 协议

OAI-PMH（Open Archives Initiative Protocol for Metadata Harvesting）是元数据批量采集的标准协议，6 个标准动词，通过 Resumption Token 分页。

### arXiv OAI-PMH

| 属性 | 值 |
|------|-----|
| Base URL | `https://oaipmh.arxiv.org/oai` |
| 认证 | 无需 |
| 速率限制 | Resumption Token 分页，无明确限制 |
| 响应格式 | XML |
| 许可 | 元数据免费可用 |
| 六个动词 | `Identify`, `ListMetadataFormats`, `ListSets`, `ListIdentifiers`, `ListRecords`, `GetRecord` |
| 元数据格式 | `arXiv`, `arXivRaw`, `dc`（Dublin Core）, `oai_dc` |
| 典型场景 | 批量采集某学科（`set=cs`）某时间段（`from=2024-01-01`）全部记录 |
| 全量下载 | AWS S3 `s3://arxiv`（Requester-Pays）或 Kaggle |
| Connector 状态 | **❌ 未实现** |

## 接入优先级建议

按"接入难度 + 数据价值 + 许可友好度"综合排序：

### 第一梯队：立即接入（低难度 + 高价值 + CC0/CC BY）

| 优先级 | 来源 | 接口类型 | 理由 |
|--------|------|---------|------|
| **P0** | OpenAlex | REST + Query Param Key | ✅ 已实现；CC0，2.4亿论文，100K/天 |
| **P0** | CrossRef | REST + 礼貌标识 | ✅ 已实现；1.8亿 DOI，Polite 池免费 |
| **P0** | World Bank | REST + 无认证 | 零认证，16K 指标，CC BY，全球覆盖 |
| **P1** | Semantic Scholar | REST + Header Key | ✅ A4 已落地（`semanticscholar.ts`）；YAML 默认 disabled |
| **P1** | PubMed | REST + Query Param Key | 生物医学权威，38 数据库，免费 Key |
| **P1** | arXiv | OAI-PMH + REST Legacy | 无认证，批量采集成熟，AI/物理预印本 |

### 第二梯队：季度内接入（中等难度 + 高价值）

| 优先级 | 来源 | 接口类型 | 理由 |
|--------|------|---------|------|
| **P2** | PatentsView | REST + Header Key | 🟡 已预留；USPTO 清洗数据，研究友好 |
| **P2** | SEC EDGAR | REST + 礼貌标识 | 零 Key，结构化财务数据（XBRL），10次/秒 |
| **P2** | Hacker News | REST + 无认证 | 零门槛，技术社区热点 |
| **P2** | ClinicalTrials.gov | REST + 无认证 | 零门槛，临床试验数据 |

### 第三梯队：按需接入（复杂认证 或 商业限制）

| 优先级 | 来源 | 接口类型 | 理由 |
|--------|------|---------|------|
| **P3** | GitHub | REST + GraphQL + Bearer | 需 PAT，60次/小时未认证太低，需 Token |
| **P3** | FRED | REST + Query Param Key | 经济数据刚需时才接，需确认商业版权 |
| **P3** | EPO OPS | REST + OAuth 2.0 | OAuth 流程复杂，2.5GB/周，欧洲专利 |
| **P3** | Google Patents | BigQuery + OAuth | 需 GCP 账号 + BigQuery SDK，1.2 亿专利 |
| **P3** | YouTube | REST + API Key | 配额紧张（搜索 100 单位/次），仅 10K/天 |

## 附：认证模式 → Connector 模板映射

对应 `src/types.ts` 的 `AuthType` 类型，各接口类型实现要点：

| AuthType | 适用来源 | BaseConnector 子类实现要点 |
|----------|---------|--------------------------|
| `query_param_key` | OpenAlex, PubMed, FRED | URL 拼接 `&api_key=...` |
| `header_custom` | SemanticScholar, PatentsView | `fetch()` 中 `headers: { "x-api-key": ... }` |
| `header_bearer` | GitHub, Reddit | `headers: { Authorization: "Bearer ..." }`，需 Token 管理 |
| `polite_id` | CrossRef, SEC EDGAR, arXiv Legacy | User-Agent / mailto 参数 |
| `oauth2` | EPO OPS, Google Patents | 需 Token 获取 + 续期流程 |
| `none` | World Bank, ClinicalTrials.gov, Hacker News | 直接 fetch，无额外 Header |
