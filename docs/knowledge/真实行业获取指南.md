# 真实行业数据库的获取指南

> **data-platform 接入状态**：已实现 **18** Connector 对照见 [实施进度总览 §2.1](../plans/实施进度总览.md#21-connector-运行时)（含 **`biorxiv_oai` ✅**）；**待接入清单与波次 5–8** → [待接入数据源清单与波次方案](../plans/待接入数据源清单与波次方案.md)。

数据是 UODE 引擎的"燃料"。获取**真实、可信、有法律授权**的行业数据，是整个系统能否产生价值的根基。下面我从**数据类别 → 具体来源 → 获取策略**三个维度系统讲解。

## 一、行业数据的六大类别与典型来源

### 📊 类别全景图

| 数据类别 | 典型问题 | 数据特点 |
|---------|---------|---------|
| **学术与科研** | 技术前沿在哪？ | 高质量、滞后 6-18 月 |
| **专利与知识产权** | 谁在做什么？ | 结构化、法律约束清晰 |
| **市场与商业** | 谁在卖、谁在买？ | 需付费、时效性强 |
| **政府与统计** | 宏观趋势如何？ | 免费、覆盖广、粒度粗 |
| **舆情与社交** | 用户在想什么？ | 海量、噪声大 |
| **行业垂直数据** | 这个领域具体发生什么？ | 专业、贵、护城河强 |

## 三、获取数据的六种合法路径

```
                   ┌─ 路径 1：开放数据 (免费 API/下载)
                   ├─ 路径 2：商业 API 订阅
   数据获取 ─────  ├─ 路径 3：数据集市场购买
                   ├─ 路径 4：合规网页抓取
                   ├─ 路径 5：合作伙伴/数据交换
                   └─ 路径 6：自建采集（用户授权）
```

### 🛣️ 路径 1：开放数据 API（首选）

**优势**：免费、合法、稳定
**关键资源**：
- **awesome-public-datasets**（GitHub 开源整理，1万+数据源）
- **Kaggle Datasets**（30万+数据集，含真实业务数据）
- **Hugging Face Datasets**（10万+，AI-ready 格式）
- **Google Dataset Search**（搜索引擎找数据集）⭐
- **Registry of Open Data on AWS**（云端大型数据集）

### 🛣️ 路径 2：商业 API 订阅

**典型聚合 API 平台**：
- **RapidAPI** —— 4万+ API 一站接入
- **Apify** —— 网页数据预制爬虫市场
- **Bright Data** —— 数据采集即服务
- **Datarade** —— 数据集采购市场 ⭐
- **AWS Data Exchange / Snowflake Marketplace** —— 云原生数据集市

### 🛣️ 路径 3：数据市场购买

**主要平台**：
- **Datarade.ai** —— 全球数据市场
- **Snowflake Marketplace** —— 云内即用
- **Databricks Marketplace** —— 同上
- **数据堂 / 聚合数据 / 京东万象** —— 中国
- **Statista / GlobalData** —— 行业报告

### 🛣️ 路径 4：合规网页抓取

**法律要点**：
- ✅ 遵守 `robots.txt`
- ✅ 遵守网站服务条款（ToS）
- ✅ 不抓取个人信息（除非授权）
- ✅ 不绕过技术防护
- ✅ 控制频率，避免影响目标服务

**工具栈**：
- **Playwright / Selenium**（浏览器自动化）
- **Scrapy**（专业爬虫框架）
- **Apify / Bright Data**（托管方案）
- **Firecrawl / Jina Reader**（AI 时代爬虫，直接给 LLM 用）⭐
- **Common Crawl**（公开网页快照，全量免费）

### 🛣️ 路径 5：合作伙伴交换

- 与行业协会合作
- 与高校、研究机构联合项目
- 数据互换（你的数据换他的数据）
- 政府开放数据合作伙伴计划

### 🛣️ 路径 6：自建采集

- 自己的产品产生的用户行为
- 通过用户授权调研、问卷
- IoT/传感器实时采集
- 众包平台（Mechanical Turk、Prolific）

## 六、给"启动期"团队的实战路线

### 第 1 周：数据资产盘点
- ✅ 列出目标行业的 5-10 个核心问题
- ✅ 反推每个问题需要什么数据
- ✅ 标注：免费可得 / 需付费 / 需自建

### 第 2-3 周：免费源接入
优先级排序：
1. **政府开放数据**（最稳定）
2. **学术 API**（OpenAlex、Semantic Scholar）
3. **专利**（Google Patents BigQuery）
4. **SEC EDGAR / 巨潮**（上市公司）

### 第 4-6 周：付费源评估
- 对每个候选付费源做 **POC**（多数支持试用）
- 计算 ROI：数据成本 vs 带来的洞察价值
- 优先选 **API 友好、文档完善** 的供应商

### 第 7 周+：建立"数据飞轮"
- 用户使用产生的反馈也是数据
- 把验证过的机遇案例沉淀为训练样本
- 数据→洞察→反馈→更好的数据，形成闭环

## 八、法律与伦理红线 ⚠️

| 必须注意 | 说明 |
|---------|------|
| **GDPR / PIPL / CCPA** | 个人数据严格管控 |
| **网站 ToS** | 部分明确禁止商业用途 |
| **Robots.txt** | 行业惯例，必须遵守 |
| **版权** | 数据可用，但聚合呈现可能侵权 |
| **数据库特殊权利**（欧盟） | 即使数据本身公开，数据库结构也受保护 |
| **反爬虫法律**（中国） | 突破技术措施可能违反《刑法》 |

> 💡 **建议**：建立**数据来源台账**，记录每条数据的出处、授权、使用范围，应对未来审计或法律询问。

## 九、终极建议：数据策略 = 长期护城河

> **API 调用让模型平等，但数据组合让你独特。**

成功的 UODE 不是用了最贵的数据，而是：

1. 🎯 **独特组合**：把 5-10 个公开数据源以独特方式融合
2. 🔄 **反馈闭环**：用户使用产生的数据是别人没有的
3. 📈 **时间累积**：3 年的连续数据 ≠ 任何人能买到的
4. 🤝 **专家网络**：人类专家的判断也是"数据"
5. 🔍 **领域 Know-how**：知道**哪条数据真正重要**

## 一句话总结

> **优质数据来源 = 60% 公开免费 + 25% 精选付费 + 10% 合作专属 + 5% 自建。**
> 起步阶段用免费的就能做出令人惊艳的 MVP；护城河来自**长期、合规、独特的组合**，而不是单一的"贵数据"。
